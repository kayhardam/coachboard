# My boards

Read with the root `AGENTS.md`, when a file in this folder is read; `CLAUDE.md` here is a symlink to this file.

`boards.ts` keeps the boards on a device; the editor (`src/components/board/BoardEditor.svelte`) shows them. Its behavior in the editor is in `src/components/board/AGENTS.md`.

- **My boards** (`src/lib/board/boards.ts`) keeps your boards in one `localStorage` key, `coachboard.boards`: the list (id, board, folder, date) and the board last opened. Folders show the most recently changed first, each in the order of the list (a training's boards in the order you run them: Move up and Move down in a board's ⋯; a board put in a folder goes to its bottom); the boards without a folder by date. A copy goes right under its original, Undo after a delete puts the board back in its place (or last, if the list got shorter meanwhile). A folder is its name: renaming one to a name in use adds its boards to the bottom of that folder. Every change goes through `update()`, which reads the list again first, so two tabs don't undo each other's work. An entry this version can't read (saved by newer code) stays in the key, hidden and in its place (`kept`), and isn't exported; My boards says nothing about it. Without the key, the board earlier versions kept (`coachboard.board`) becomes the first board, once, unless it is an untouched default lineup (`isUntouchedDefault()`, every lineup any version could have saved); the old key stays, for a rollback;
- **Export all boards** writes one file of links (`exportFile()` in `boards.ts`): `{ "coachboard": 1, "boards": [{ "link", "folder"?, "at" }] }`, each link the full URL of the board page (`…/board/#t=2.…`), the date as ISO. No second format: `importFile()` reads every link with `decode()`. The file is a contract like the link: an export must import forever (`fixtures/export/export-1.json`). The boards go in the order of the list, so a folder imports in its order. Export first saves the board on the court if its save (300 ms) is still waiting, under its own id, so the file has the latest change and no copy is made. It shows only when there are boards;
- **Import boards** only adds: each board gets a new id and keeps its folder and date from the file, last in the list in the file's order (in a folder the device has, at its bottom); the board on the court and the board last opened stay. A board already in the same folder (the boards without one count as one folder), or earlier in the file in that folder, is left out: so a copied folder comes along with its unchanged boards, and the same file twice adds nothing. `sameBoard()` in `format.ts` compares boards, not link text, because compression can give other bytes per browser. The notice counts only the boards added;
